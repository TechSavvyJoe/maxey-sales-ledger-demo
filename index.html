Sales Ledger

Open the app from its local web address

Double-clicking index.html does not start the secure local app. Start Sales Ledger first, then use the same address every time so your saved sales stay together.

Open Sales Ledger
  1. On Mac, double-click Start Maxey Sales Ledger.command. On Windows, double-click Start Maxey Sales Ledger.cmd.
  2. Leave the small Terminal window open while you use the app.
  3. Return to http://127.0.0.1:4180/ whenever you need the tracker.

Your records remain in this browser profile. The launcher does not upload them or enable cloud sync.
